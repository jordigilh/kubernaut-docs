    Helm Chart Configuration Reference¶

    Point-in-time mirror -- may drift from upstream

    This page is a manually-ported snapshot of the kubernaut repo's auto-generated docs/generated/helm-values-reference.md (generated from charts/kubernaut/values.schema.json by hack/gen-helm-config-docs, commit d5a4a8709). It documents every leaf parameter in the schema, including internal and rarely-touched fields.

    For the current, always-accurate version, see the live file on GitHub: docs/generated/helm-values-reference.md.

    If you only need the handful of fields required to get a working install, start with the Minimal values.yaml section instead -- this page is a reference for every possible override, not a getting-started guide.

    Parameters are grouped by top-level values.yaml key (e.g. kubernautAgent.llmProfileRef lives under kubernautAgent). A default of `` (empty backticks) means the field has no explicit schema default -- typically an object/array whose absence is itself the meaningful default (nothing rendered), not an empty string.
